# py_Ass8
For submission of Assignment 8

### Execution Steps

1. Install Python (if not installed)

2. Install Flask:

```
pip install flask
```

3. Project structure should be:

```
project_folder/
│
├── app.py
│
└── templates/
    ├── registration.html
    └── register_successful.html
```

4. Open terminal and go to project folder:

```
cd path_to_project_folder
```

5. Run the application:

```
python app.py
```

6. Open browser and go to:

```
http://127.0.0.1:5000/
```

7. Fill the form and submit to see the result page.
